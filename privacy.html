Privacy Policy

Personal MCP Assistant · Last updated: November 20, 2026

1. About this application

Personal MCP Assistant is a private, single-user application. Its owner uses it on their own computer to read their own Gmail messages and Google Calendar events through Google’s APIs. It is not offered to anyone else, and it has no servers, user accounts or databases.

2. Data the application accesses

With the owner’s consent, the application has read-only access to Gmail messages and Google Calendar events of the owner’s Google account. It cannot send, modify or delete messages or events.

3. How the data is used

Data is read only when the owner makes a request, and only on the owner’s computer. The results may be passed to the AI assistant software that the owner runs, and to the language-model service the owner has chosen, solely to answer the owner’s own requests.

4. Storage

The application does not keep copies of email or calendar content. The OAuth credentials that let it connect to the owner’s Google account are stored only in files on the owner’s computer, with access limited to the owner.

5. Sharing

The application does not sell, rent or share Google user data with third parties, does not use it for advertising, and does not allow anyone other than the owner to read it.

6. Google API Services User Data Policy

The use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

7. Revoking access and deleting data

The owner can revoke the application’s access at any time at myaccount.google.com/permissions and delete the locally stored credentials from their computer.

8. Changes

If this policy changes, the new version will be published on this page with an updated date.

Политика конфиденциальности

Personal MCP Assistant · Обновлено: 20 ноября 2026 г.

1. О приложении

Personal MCP Assistant — частное приложение для одного пользователя. Его владелец запускает его на собственном компьютере, чтобы читать свою почту Gmail и события Google Календаря через API Google. Приложение не предоставляется другим людям, у него нет серверов, учётных записей и баз данных.

2. Какие данные использует приложение

С согласия владельца приложение получает доступ только на чтение к сообщениям Gmail и событиям Google Календаря его аккаунта Google. Отправлять, изменять или удалять сообщения и события оно не может.

3. Как используются данные

Данные читаются только по запросу владельца и только на его компьютере. Результаты могут передаваться программе ИИ-ассистента, которую запускает владелец, и сервису языковой модели, выбранному владельцем, исключительно для ответа на его собственные запросы.

4. Хранение

Приложение не сохраняет копии писем и событий. Учётные данные OAuth, с помощью которых оно подключается к аккаунту Google, хранятся только в файлах на компьютере владельца с доступом только для него.

5. Передача третьим лицам

Приложение не продаёт, не сдаёт в аренду и не передаёт данные пользователя Google третьим лицам, не использует их для рекламы и не позволяет читать их никому, кроме владельца.

6. Политика Google в отношении пользовательских данных

Использование и передача любому другому приложению информации, полученной из API Google, соответствуют Политике Google API Services User Data Policy, включая требования ограниченного использования (Limited Use).

7. Отзыв доступа и удаление данных

Владелец может в любой момент отозвать доступ приложения на странице myaccount.google.com/permissions и удалить сохранённые на компьютере учётные данные.

8. Изменения

При изменении политики новая версия будет опубликована на этой странице с обновлённой датой.
